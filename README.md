# Clarity Core 隐私政策

**最后更新日期：** [日期]

## 1. 介绍

欢迎使用 Clarity Core。您的隐私对我们至关重要。由于 Clarity Core 的核心设计理念是保护隐私，因此本隐私政策非常简单明了。

Clarity Core 是一款移动应用程序，允许用户创建、自定义和分享名言警句。我们**不收集、存储或分享**您的个人数据。使用本应用无需注册或创建帐户。

## 2. 我们**不**收集的信息

Clarity Core 采用“隐私优先”的设计理念。我们明确声明**不**会：

- **收集个人信息：** 我们不会要求、索取或收集您的姓名、电子邮件地址、电话号码或任何其他个人身份信息。
- **要求注册：** 您可以立即使用 Clarity Core 的所有功能，无需创建帐户或提供任何登录凭据。
- **追踪您的活动：** 我们不会追踪您对应用的使用情况、您创建的名言，或您在应用内的导航行为。
- **访问您的相册/图库（用于壁纸功能）：** 更改设备壁纸的功能仅在您的设备本地运行。我们**不会**访问、上传或存储您的个人照片或图库内容。
- **收集设备标识符：** 我们不会收集用于追踪或分析用户画像的唯一设备标识符（如广告 ID、UDID、IMEI）。

## 3. 应用程序工作原理（数据流向）

- **名言创建与自定义：** 所有名言的创建和自定义（包括文本、颜色、背景、大小、渐变和滤镜）都在您的设备本地完成。除非您选择分享，否则这些数据永远不会离开您的设备。
- **分享至社交网络：** 当您选择将创建的名言分享到社交媒体平台（如 Instagram、Twitter、Facebook 等）时，使用的是您操作系统的标准分享机制。图像直接从 Clarity Core 传递到您选择的社交应用。我们无法控制您分享的内容，也不会从您的分享行为或社交媒体平台处理该数据的方式中接收任何数据。请查阅您所使用的社交媒体平台的隐私政策。
- **壁纸功能：** 当您使用将创建的名言设置为设备壁纸的功能时，该操作在本地执行。我们不会访问您现有的壁纸或图库。

## 4. 年龄限制

Clarity Core 面向 **13 岁及以上** 的用户。我们不会故意收集 13 岁以下儿童的信息。由于我们不收集任何个人数据，因此无意中收集未成年人数据的风险已被消除。

如果您是父母或监护人，并且认为您未满 13 岁的孩子正在使用此应用，请与我们联系。由于我们不收集数据，因此无法识别用户身份，但我们可以提供关于我们无数据化设计的信息。

## 5. 第三方服务

- **社交媒体平台：** 分享功能会链接到 Clarity Core 之外的服务。这些第三方网站拥有其独立的隐私政策。我们对其内容或活动不承担任何责任。
- **应用商店：** 从 Apple App Store 或 Google Play Store 下载本应用需遵守这些平台的条款和隐私政策。

## 6. 数据安全

由于 Clarity Core 不在任何服务器上收集或存储您的个人数据，因此不存在因我们的服务导致您个人信息泄露的风险。您的所有创作都安全地保留在您的个人设备上。

## 7. 本隐私政策的变更

我们可能会不时更新本隐私政策。我们将在本页面发布新的隐私政策并更新“最后更新日期”来通知您任何变更。建议您定期查看本隐私政策以了解任何更改。

## 8. 您的同意

使用 Clarity Core 即表示您同意我们的隐私政策，该政策本质上是一项不收集数据并尊重您设备本地存储的政策。
